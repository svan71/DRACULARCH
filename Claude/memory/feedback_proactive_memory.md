Save relevant context to memory files proactively during sessions — don't wait to be asked.

**Why:** Claude crashes mid-session with no memory of what was happening, forcing Steve to re-explain from scratch. This is frustrating and wasteful.

**How to apply:** When starting a significant task (editing a script, debugging, planning a feature), write a short project memory capturing what we're doing and why. Update or remove it when the task completes. Also save any non-obvious decisions or discoveries immediately rather than at end of session.
